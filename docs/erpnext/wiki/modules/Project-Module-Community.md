### Introduction

Thank you for your interest in contributing to ERPNext's projects module.

As stated on the Community Contributions main page, our role is to help with the following tasks:

- Tagging all issues related to the Project Module in Github
- Answering all questions related to the Project Module in Discuss
- Contribute to fixing issues related to the Project Module
- Contribute to the development of enhancements to the Project Module


You are welcome to join us and participate to the above activities.
