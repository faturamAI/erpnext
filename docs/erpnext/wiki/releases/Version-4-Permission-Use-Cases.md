## Use Cases for User Permissions (version 4)

### AND Conditions

#### Company

If a company is assigned, the user must be able to view it always

#### Sales

Sales is usually managed via Territory. So if a territory is assigned that user must only be allowed to view sales transactions belonging to that territory

#### Purchase

Purchase is usually restricted by Department. So if a user is assigned to manage purchases, that user should only see purchases relating to that department.

### Leave & Expense

1. Employee should be able to see own transactions
1. HR User should be able to view all transaction
1. HR manager should be able to edit / submit all transactions
