[ERPNext](http://erpnext.org) is an open source ERP written on Python and has MySQL at the back-end and includes Financial Accounting, Inventory Management, CRM, Project Management, Human Resource MS. It is designed to be easy to use and ideal for small businesses.

[See Wiki Pages](https://github.com/frappe/erpnext/wiki/_pages)

### Install

To Install ERPNext, use [Frappe Bench](https://github.com/frappe/bench)
